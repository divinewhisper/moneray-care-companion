# หน้า Admin อนุมัติแพทย์ + สิทธิ์ admin

## สถานะที่ทำเสร็จแล้ว (จากรอบก่อน)
- ให้สิทธิ์ `admin` กับบัญชี 22047@satitpatumwan.ac.th ในตาราง `user_roles` เรียบร้อยแล้ว (ล็อกอินใหม่เพื่อให้สิทธิ์มีผล)
- สร้างหน้า `/admin` แล้ว: ตรวจสิทธิ์ admin, แสดงรายชื่อแพทย์ที่ลงทะเบียน, เปิดดูไฟล์ใบประกอบวิชาชีพ (ลิงก์ชั่วคราว), ปุ่ม "อนุมัติ" / "ไม่ผ่าน"
- เซิร์ฟเวอร์ฟังก์ชัน `src/lib/admin.functions.ts`: `amIAdmin`, `listDoctorProfiles`, `setDoctorStatus`, `getLicenseUrl` — ทุกตัวตรวจสิทธิ์ admin ฝั่งเซิร์ฟเวอร์

## งานที่เหลือในแผนนี้
1. **เพิ่มทางเข้าหน้า Admin** — ปุ่ม/ลิงก์ "หน้าผู้ดูแลระบบ" ในหน้าโฮม แสดงเฉพาะบัญชีที่เป็น admin (ซ่อนจากผู้ใช้ทั่วไป)
2. **ตรวจ build** — ยืนยันว่าโค้ดทั้งหมดคอมไพล์ผ่าน
3. **ทดสอบจริงด้วยเบราว์เซอร์** — ล็อกอินด้วยบัญชี admin, เปิด `/admin`, ดูรายชื่อแพทย์ และทดสอบกดอนุมัติ

## รายละเอียดทางเทคนิค
- แก้ `src/routes/_authenticated/home.tsx`: เรียก `amIAdmin` (server fn ที่มีอยู่แล้ว) ผ่าน `useQuery` แล้วแสดงการ์ดลิงก์ไป `/admin` เมื่อ `isAdmin === true`
- ไม่แตะ RLS/ตารางเดิม — นโยบาย `doctor_profiles` รองรับ admin อยู่แล้ว
- ทดสอบด้วย Playwright บน localhost:8080
