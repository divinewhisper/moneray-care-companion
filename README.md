# Moneray Health Hub

Moneray



สร้างแอปพลิเคชัน “Moneray” ซึ่งเป็นแอปพลิเคชั่นสาธารณะด้านสุขภาพที่มีคุณสมบัติดังนี้



   - ด้านหน้าตาทั่วไปของแอปพลิเคชัน

แอปพลิเคชันมีขนาดเท่ากับหน้าจอโทรศัพท์

ใช้พื้นหลังสีขาว โดยที่ตัว UI ของแอปพลิเคชันมีสีฟ้า (122, 170, 230) ตามระบบสี RGB และ สีส้ม (230, 170, 122) เพื่อแยกฟังก์ชันต่างๆออกจากกันอย่างชัดเจน

UI มีขนาดใหญ่ เหมาะสำหรับผู้สูงอายุโดยที่มีขนาด 18pt ถึง 36pt สำหรับตัวอักษร และมีขนาดมากกว่านั้นสำหรับฟังก์ชั่นหลัก เหมาะกับผู้สูงอายุและผู้ป่วยโรคตาบอดสี



   - การลงทะเบียนเข้าใช้งานแอปพลิเคชัน

มีการลงทะเบียนผ่าน E-mail, Facebook หรือ Apple ID

จากนั้นเมื่อลงทะเบียนเสร็จจะมีการส่งอีเมลแจ้งเตือน

และมีการให้ตั้งชื่อผู้ใช้โดยใช้ ชื่อ และ นามสกุล

มีการกรอกเบอร์โทรสำหรับเป็นช่องทางติดต่อ

มีการกรอกที่อยู่สำหรับจัดส่งพัสดุ



  - หน้าโฮมเพจของแอปพลิเคชัน

ด้านบนมีการบอก ชื่อ นามสกุล สามารถกดปิดเพื่อไม่ให้แสดงได้ เมื่อกดเข้าไปจะนำไปสู่ข้อมูลของบัญชี เช่น E-mail, เบอร์โทรศัพท์, ที่อยู่ สามารดกดปิดเพื่อไม่ให้แสดงได้

ถัดลงมาเป็น Search Bar สามารถค้นหารายชื่อแพทย์ หรือ บทความสุขภาพได้

ทั้งข้อมูลผู้ใช้และ Search Bar มีพื้นหลัง (ไม่รวม Ui) เป็นแถบสีน้ำเงิน (เปรียบเสมือนขอบบนของแอปพลิเคชัน)

ถัดลงมาเป็นข้อมูลเกี่ยวกับการดูแลสุขภาพประจำวัน (ยารักษาที่ต้องรับประทานประจำ หรือกิจกรรมกายภาพบำบัด) โดยบอกตารางเวลา และมีการแจ้งเตือนเมื่อถึงเวลา [UI นี้ มีขนาดใหญ่รองลงมาจาก การเลือกใช้บริการสุขภาพ] อยู่ในบรรทัดเดียวเดี่ยวๆเป็นแนวยาว เมื่อคลิกเข้าไปสามารถแก้ไขข้อมูลยารักษาได้ เช่น ชื่อ, ขนาดที่รับประทานต่อครั้ง, ช่วงเวลาที่ต้องรับประทานยา

ถัดลงมาอีกมี UI ให้เลือกระหว่างการใช้บริการด้าน “สุขภาพกาย” (สี 122, 170, 230) หรือ “สุขภาพจิต” (สี 230, 170, 122) (ทั้งคู่มีไอคอนประกอบ) [UI ขนาดใหญ่ที่สุด] อยู่ในบรรทัดเดียวกัน แบ่ง ซ้าย-ขวา เมื่อคลิกเข้าไปจะไปอีกหน้าหนึ่ง (รายละเอียดในหัวข้อถัดไป)

ถัดลงมาคือ UI ขนาดกลางบอกการนัดพบแพทย์ครั้งถัดไป (หากมี) โดยบอกข้อมูลของแพทย์ วันที่ และ เวลานัดหมาย

ถัดลงมาเป็นระบบ Tracking พัสดุยารักษาที่กำลังจัดส่งมาตามที่อยู่



  - หน้าต่างที่ขึ้นมาหลังจากคลิกไปที่ “สุขภาพกาย” หรือ “สุขภาพจิต”

ระบบจะจัดแยกสิ่งที่ผู้ใช้เลือกไว้ เป็น 2 Category ไม่นำมารวมกัน คือ ด้านสุขภาพกาย และ ด้านสุขภาพจิต

เมื่อคลิกเข้าไปแล้วจะมี UI ให้เลือกอีก 2 อันขนาดใหญ่ที่สุด คือ “วินิจฉัยโรค” หรือ “ติดตามอาการหลังการรักษา”

เมื่อคลิกเข้าไป หัวข้อการสนทนาจะถูกบันทึกตามสิ่งที่เลือก โดยที่มีตัวเลือก 2 ตัวเลือก คือ สนทนากับแพทย์โดยตรงผ่านแชตและวิดีโอคอล หรือ สนทนากับแชตบอต

โดยที่การสนทนาผ่านแชตทั้งหมดจะถูกบันทึกประวัติเอาไว้ให้สนทนาต่อจากเดิมได้ หรือสามารถเลือกขึ้นหัวข้อการสนทนาครั้งใหม่ได้

หากหน้าต่างแรกที่เลือกคือ “สุขภาพจิต” แชตบอตที่คุยด้วย จะมีการแฝงคำชม คำให้กำลังใจ ไว้ในบทสนทนาต่างๆด้วย เพื่อให้กำลังใจผู้ใช้งาน

โดยที่โทนสีของ UI ขณะที่อยู่ในหน้าต่าง วินิจฉัยโรคสุขภาพกาย จะเป็นสีน้ำเงิน (17, 70, 102)

โทนสีของ UI ขณะที่อยู่ในหน้าต่าง ติดตามอาการหลังจากการรักษาโรคทางสุขภาพกาย จะเป็นฟ้าอ่อน (34, 161, 240)

โทนสีของ UI ขณะที่อยู่ในหน้าต่าง วินิจฉัยโรคสุขภาพจิต จะเป็นสีส้มเข้ม (255, 116, 23)

และโทนสีของ UI ขณะที่อยู่ในหน้าต่าง การติดตามอาการหลังจากการรักษาโรคทางสุขภาพจิต จะเป็นสีส้มอ่อน (247, 179, 134)



  - ผู้ใช้สามารถเข้าไปตรวจสอบและพิมพ์ใบสั่งยาออนไลน์ออกมาเพื่อนำไปจัดซื้อยารักษาที่ร้านเภสัชกรแถวบ้านได้ด้วยตนเอง



  - แอปพลิเคชันมีโลโก้อยู่ตามมุม/ขอบในหน้าเพจต่างๆ โดยที่เป็นรูปที่แนบมาดังนี้
